# 廿四道·城外 — 雨夜破祠（试玩）

浏览器打开本仓库 GitHub Pages 即可游玩第一章。游戏为 **landscape 16:9** 舞台（匹配当前横版底板与分层立绘素材）。

打开后是顾山首页（恋与深空式陪伴）：立绘置于 16:9 舞台、轻触热区短句，底栏 **主线 | 家园 | 图鉴 | 明信片**。

- **主线**：雨夜救助 → 次日相处了解（陌生救命 → 同室戒备 → 立住信任）
- **家园**：破祠四热区（榻 / 神位 / 灶 / 门）；添柴、盛水、整理榻席、关门避雨；状态 localStorage 持久
- **图鉴**：R 垄上烟 / SR 雨蓑归 / SSR 甲上霜 / UR 星河渡（含心迹与 align / branched 标记）；卡片与详情舞台均为 16:9

桌面：居中舞台（最大约 1280px 宽），外侧可有黑边 letterbox；舞台内不裁切 16:9 底板。
