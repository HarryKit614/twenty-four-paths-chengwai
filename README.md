# 廿四道·城外 — 雨夜破祠（试玩）

手机浏览器打开本仓库 GitHub Pages 即可游玩第一章。

打开后是顾山首页（恋与深空式陪伴）：真竖立绘居中、轻触热区短句，底栏 **主线 | 家园 | 图鉴 | 明信片**。

- **主线**：雨夜救助 → 次日相处了解（陌生救命 → 同室戒备 → 立住信任）
- **家园**：破祠四热区（榻 / 神位 / 灶 / 门）；添柴、盛水、整理榻席、关门避雨；状态 localStorage 持久
- **图鉴**：R 垄上烟 / SR 雨蓑归 / SSR 甲上霜（含心迹与 align / branched 标记）

素材为竖版 9:16，适配手机全屏。
